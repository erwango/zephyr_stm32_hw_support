STM32 HW Support in Zephyr

Auto-generated view of which STM32 peripherals (devicetree compatible) are upstream in zephyrproject-rtos/zephyr, per STM32 series. Devicetree is treated as the source of truth: a node is only ever upstreamed together with its driver. Refreshed daily on main, snapshotted once per stable release.

Series

Rows = Cortex core, columns = series, cells = SoC count. Click a cell for the SoC list. MPU = STM32MPx microprocessor; Zephyr runs on that one core only.

API coverage

Click a row (or ▸) to expand per-compatible detail. Misc = bindings not tied to a specific peripheral category (e.g. NPU, RAM config).

Note: on-chip vs. ported matching between STM32Cube (hal_stm32) and Zephyr devicetree is automated via a curated IP lookup table and may not be 100% accurate. Treat it as a hint, not a certified spec. Press S to toggle the "Ported %" stats.
