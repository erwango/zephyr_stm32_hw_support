STM32 HW Support in Zephyr

Auto-generated view of which STM32 peripherals (devicetree compatible) are upstream in zephyrproject-rtos/zephyr, per STM32 series. Devicetree is treated as the source of truth: a node is only ever upstreamed together with its driver. Refreshed daily on main, snapshotted once per stable release.

Series

One row per Cortex core, one column per series; each cell is the number of SoC part numbers for that series that use that core (a series with more than one Zephyr-supported core, e.g. STM32H7's M4/M7 dual-core parts, has a cell filled in on more than one row). Click a cell to see that series' SoC list. A MPU badge marks STM32MPx microprocessors: Zephyr targets that one core only, and any other on-chip core (e.g. an application processor) is outside Zephyr's scope. SoC count is the number of SoC part numbers listed for that series in Zephyr's own catalog (soc/st/stm32/soc.yml), i.e. SoCs with an upstream Zephyr port — not ST's full orderable part catalog, which may list additional package/temperature variants not individually declared in Zephyr.

API coverage

One row per category by default; click a row (or the ▸) to expand the per-compatible detail. The Misc group holds APIs that are either inherently miscellaneous, or supported on only a single STM32 series — their original category is noted next to the compatible when applicable.

clock and pinctrl are mandatory baseline requirements for any upstream SoC port and are omitted from the grid above. Generated by scripts/scan_zephyr.py.
